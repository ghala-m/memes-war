# 🎮 Memes War — حرب الميمز

**Memes War** is a real-time multiplayer party game. Everyone answers the same prompt with a meme, then the room votes for the funniest one. Fully bilingual (English 🇬🇧 / العربية 🇸🇦) with RTL support, dark mode, and a pastel 16-bit / Y2K look.

🔗 **Live app:** https://memes-war.lovable.app

---

## ✨ Highlights

- **Instant rooms** — the host creates a room, everyone joins with a 6-character code or by scanning the lobby QR code. No sign-up.
- **Meme picker** — a full-screen, two-column masonry browser with category tabs (Trend, Happy, Sad, Angry, Cringe, Scared, and more) so you can find the perfect reaction fast.
- **Real-time rounds** — Prompt → Submit → Reveal → Vote → Score, with synced timers, host pause/skip, and early advance when everyone is done.
- **Question control** — the host can queue specific questions before starting, or add their own to a private library. Remaining rounds pull random questions from a 200-question bilingual bank.
- **Live leaderboard** — round scoring, a winner reveal, and a final champion screen.
- **Bilingual + themes** — one-tap English/Arabic switch and light/dark mode.

## 🕹️ How to play

1. The host opens the app and taps **Create Room**, picks the number of rounds, and (optionally) chooses the questions.
2. Players tap **Join Room** and enter the code — or scan the QR code shown in the lobby.
3. Each round shows a prompt. Everyone picks one meme that answers it best.
4. All picks are revealed anonymously, then everyone votes (you can't vote for your own).
5. Points are awarded, and after the final round the champion is crowned.

### Scoring

| Action | Points |
| --- | --- |
| Your meme wins the round | **+10** |
| Each vote your meme receives | **+5** |
| You voted for the winning meme | **+3** |

Rooms support **3–20 players**.

## 🧱 Tech stack

| Layer | Choice |
| --- | --- |
| Framework | TanStack Start (React 19 + Vite 7) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 + custom design tokens |
| Backend | Lovable Cloud (Postgres, storage, server functions) |
| State sync | Server functions + fast polling (~1.2s) |

### Data model

- `rooms` — code, phase, round, timers, queued questions
- `players` — nickname, score, host flag, session token
- `prompts` — bilingual question bank (public + host-private libraries)
- `memes` — meme catalogue with category tags
- `submissions` / `votes` — per-round picks and votes

Game rules run server-side with versioned phase transitions, so scoring can never be applied twice.

## 🚀 Run locally

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

The app starts on `http://localhost:8080`. Backend credentials live in `.env` (`VITE_SUPABASE_*`) and are generated by Lovable Cloud.
